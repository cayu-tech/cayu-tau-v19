# Tau V19 workflow candidate — 2026-09-28

Isolated successor to frozen V18. The selected native advisory `constraints-v4`
profile uses one acting model, compact outcome patches, decision facts, optional
constraint notes and automatically recorded execution receipts. The model receives
`workflow_profile.py` instructions; tests verify the assembled request.

- Scope works with default, lexical, literal or explicit scoped search. The actor
  selects public directory IDs before ranking. Incomplete source windows remain
  navigation. No regex intent classification or hidden evaluator data is added.
- The outcome interface and context hide nested obligations and planned tool packets.
  The backend retains atomic revision, reference, dependency and completion validation.
- Advisory mode warns on repeated rejected operations without stopping at eight.
  Invalid calls remain rejected; overall task and step limits still apply.
- In the selected constraints profile, notes are optional. Presence/exposure locks
  and model-authored conflict vetoes are removed. Notes still survive compaction.
  Unknown/contradicted claims stay visible and never become execution permission.
  Actual policy and authoritative execution checks still apply.
- Contradictions may cite one source containing incompatible claims. Citation
  availability does not prove interpretation. No extra state store or reviewer.
- Reports preserve Tau rewards and separately show public/private tool errors,
  partial note/batch errors, simulator protocol errors and resource stops.

The screen uses two-hour actor time, 10 transient model attempts, 180K estimated
compaction, a 150K advisory warning and two isolated workers. Six previously studied
tasks include three passing controls; this is neither an official score nor a holdout.
Old candidates/runs remain preserved. Legacy enforced, packet and notebook profiles
are not this experiment. Source pins and all limits are in artifacts/protocol.json.

See ../agent-documents/tau-v19-workflow-candidate-20260928.md for rationale,
qualification and live results. Improvement requires measured task outcomes.
